# SimpleCast 0.9.0 beta 6

Beta 6 makes everyday server selection faster and adds three saved appearance
themes.

## What is new

- A server dropdown directly on the Dashboard.
- **Add server**, **Edit**, **Delete**, and **Manage stations** actions beside
  the dropdown.
- A clear confirmation prompt before a server and its saved password are
  deleted.
- Existing six-station favorites remain available beneath the server controls.
- Advanced multi-destination inclusion and favorite management remain available
  through **Manage stations**.
- Three themes under Settings → Appearance:
  - **Modern & sleek**
  - **Classic SimpleCast**
  - **Beginner friendly**
- Theme changes apply immediately and persist across restarts.
- The beginner theme uses higher contrast, larger text, and roomier controls.

## Verification

- All 67 automated tests pass.
- The source application opened, rendered all three themes, switched stations,
  displayed the Settings appearance selector, and closed cleanly.

The binaries are intentionally unsigned. Windows SmartScreen or Smart App
Control may display a warning.
