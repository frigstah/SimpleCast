# SimpleCast 0.9.0 beta 12

Beta 12 corrects the spelling in the SimpleCast footer attribution.

## What is new

- The footer now reads:
  `SimpleCast is developed by DoverSoft, please provide feedback if you encounter issues`.
- The integrated borderless Windows frame and all beta 11 functionality are
  retained.

## Verification

- All 74 automated tests pass.
- The packaged Studio Dark window displays the corrected footer and closes
  cleanly.

The binaries are intentionally unsigned. Windows SmartScreen or Smart App
Control may display a warning.
