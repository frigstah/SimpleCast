# SimpleCast 0.9.0 beta 7

Beta 7 adds four complete interface skins without removing any broadcasting
features.

## What is new

- **Classic SimpleCast** keeps the familiar sidebar workflow and all three
  existing appearance variations.
- **Broadcast Console** provides a compact dark two-column broadcasting
  console.
- **Studio Workspace** provides a spacious light three-column workspace with
  top navigation.
- **Studio Dark** combines the studio workflow with a dark control-room
  appearance.
- Every skin includes the server dropdown and management actions, six
  favorites, audio source controls, processing, stereo meters, quality and
  sample-rate controls, station testing, manual now-playing metadata, listener
  information, sound comparison, recording, and broadcasting.
- Skin selection is saved under **Settings → Appearance**.
- Because a skin changes the complete window structure, SimpleCast offers a
  controlled restart to apply it. Restart is prevented while broadcasting or
  recording.
- The existing Modern & sleek, Classic SimpleCast, and Beginner friendly
  variations remain available within the Classic SimpleCast skin.

## Verification

- All 68 automated tests pass.
- All four skins opened with six favorites and the complete functional control
  set, displayed the correct Appearance state, and closed cleanly.
- The controlled restart path shut down background components and requested
  exactly one relaunch.

The binaries are intentionally unsigned. Windows SmartScreen or Smart App
Control may display a warning.
